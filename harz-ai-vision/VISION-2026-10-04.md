# HARZ AI — THE FINISHED VISION (owner statement, Oct 4, 2026)

Owner's own words, on record. This is the target the substrate work serves.

## The vision
1. ONE HARZ INTELLIGENCE LAYER — natural voice/text commands decomposed into agents, not one
   external model. "HARZ, investigate this company, read these PDFs, compare the evidence,
   calculate the numbers, prepare a report."
2. MULTIMODAL — text, voice, images, video, PDFs/ebooks, links, files; moving between them
   (voice -> text -> reasoning -> document -> voice).
3. AGENTS WORKING TOGETHER — the graph already under construction: Search-1 -> Reasoner-1 ->
   Planner-1 -> Code-1 -> Verify-1. External providers are FALLBACKS, never HARZ's identity.
4. IT BUILDS THINGS — "Build me a school-management system": plan, generate, test, verify,
   package, deploy into the HARZ ecosystem.
5. SOVEREIGN MODE — Internet available: use external resources when permitted. Internet
   unavailable: continue from local capability/state. The internetless field test is part of
   this vision, not a separate experiment.
6. HARZ BECOMES AN ENVIRONMENT — not "open an AI app" but an intelligence layer underneath the
   digital world: search, payments, documents, identity, .harz services, agents, creation,
   eventually communication.

## The strongest version (owner, verbatim)
"HARZ can remain useful even when the external AI/model/provider disappears."

## Honest decomposition of that sentence (Magani, same day)
Sovereignty splits into two separable problems:
(a) STATE — records, seals, ledgers, resolution survive without internet. This is what the
    internetless v0.2 field gate is closing RIGHT NOW (create -> seal -> persist -> kill ->
    reboot -> verify -> tamper -> detect -> refuse).
(b) REASONING — inference capacity without external providers. NOT yet built. Nemotron via
    OpenRouter is still an external provider. The sovereign-inference rung (local models on
    phone/laptop hardware, the swappable-brain idea from Phase 3) is a later, separate build.
Sovereign records = proven path. Sovereign reasoning = honest frontier, not yet claimed.

## Sequencing discipline (standing)
The vision does not jump the gates: two-phone field run closes the integrity/durability
primitive first; the intelligence layer stands on proven substrate. Rung 4 (one real user,
candidate: Jalingo cooperative ledger) is where HARZ-the-environment meets its first citizen.
