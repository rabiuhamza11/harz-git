# HARZ OFFLINE KNOWLEDGE EXPANSION — WORKSTREAM CHARTER (Oct 11, 2026)

Owner direction (forwarded plan, accepted): six coordinated teams, three
stages, one master corpus, no agent forks. Scale ruling: C — a substantial
offline reference library first, then an expandable web archive.

## LAWS (binding on all teams)

1. One master corpus (harz-million-corpus + accepted satellite stores);
   no agent forks.
2. Evidence first: measurements state STORED / SEARCHABLE / USABLE
   separately; record counts never imply usability.
3. Frozen systems stay frozen: kb5k 5K core (seal 0a5c75d4), Internetless
   foundations, 15MB phone-install limit, 5-gate promotion rules.
4. No uncontrolled bulk ingestion; sources carry license + provenance.
5. Backup-first: no in-place replacement without verified recovery.
6. Dedupe laws before write; every batch verified against its manifest.

## STAGES

Stage 1 RECOVER: reconcile (Team A, v0 DONE tonight), recover full text
already held (Team B), measure usable knowledge today.
Stage 2 EXPAND: verified high-value collections (Teams C+D), resumable
ingestion (Team E), offline packages with independent acceptance (F).
Stage 3 OPTIMIZE: coverage, dedupe, retrieval quality, storage efficiency
under frozen tests.

for — 881,966 Wikipedia docs (including Hausa 103,764, Igbo 46,259,
